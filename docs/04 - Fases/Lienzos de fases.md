## Cómo se usan

- Cada lienzo es independiente y se puede abrir, mover y editar en Obsidian.
- Las aristas conectan la fase con sus sub-fases y con el criterio de aceptación.
- Si una sub-fase cambia, se actualiza el lienzo correspondiente y el [[Roadmap]].
